# Provider brand marks

Ollama, OpenAI, Claude, Gemini, Groq, DeepSeek, Mistral and OpenRouter PNGs
are the unmodified light and dark marks from **Lobe Icons 1.97.1**:

- Source: https://github.com/lobehub/lobe-icons
- Package: https://unpkg.com/@lobehub/icons-static-png@1.97.1/
- Files: `light/{provider}.png` and `dark/{provider}.png`
- The `anthropic.png` files use `claude.png` from the package, matching the
  **Claude** name in the provider picker.
- License: MIT; see `LOBE-ICONS-LICENSE` in this directory.

`bionic.png` is Bionic GPT's official GitHub organization avatar:
https://github.com/bionic-gpt.png?size=128

Provider trademarks belong to their respective owners. These marks identify
the services that the user can connect; they do not imply endorsement.
Custom endpoints use the app's connection icon because they have no single brand.
Logos are bundled locally, so opening a page makes no external image requests.
